# plasma-colors
Some color and theme customizations for KDE Plasma 6

- `ClearSimple/`, `color-schemes/`: the ClearSimple global theme and color scheme
- `Konsole/`: Konsole color schemes
- `colored-plasma-logo/`: splash screen with the colored Plasma logo
- `cursors/`: the Pastel Paws and Cat Paw cursor themes (see [cursors/README.md](cursors/README.md))

This repository was developed with the help of an LLM (Claude).
